关于
WiFi 通话 IMS 服务：用软件建立 VoWiFi（IKEv2/EAP-AKA 隧道 + IMS 注册），作为系统 IMS 服务接管 WLAN 通话，通话和短信直接用系统电话、系统短信。协议实现依据 3GPP TS 24.302 / 33.402 / 24.229 / 33.203 / 24.341 独立编写。
目前仅在 realme RMX6699（Android 16 / ColorOS / 骁龙，KernelSU）上验证可用，其他机型、系统和 root 方案均未测试。
